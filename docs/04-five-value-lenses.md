# The Five Technology Value Lenses

## 1. Financial value

Examples:
- vendor consolidation;
- licence rationalisation;
- avoided infrastructure refresh;
- reduced third-party spend;
- cloud optimisation;
- reduced support cost;
- revenue enablement.

Measures:
- annualised saving;
- avoided cost;
- TCO reduction;
- cost per user / transaction / service;
- payback period where meaningful.

## 2. Productivity and capacity value

Examples:
- automation;
- reduced manual processing;
- faster onboarding;
- fewer hand-offs;
- improved service-desk flow.

Measures:
- hours returned;
- cycle time;
- throughput;
- rework rate;
- automation rate;
- capacity released.

Returned time should not automatically be presented as cash saving. It may represent capacity, improved service, avoided hiring or redeployment.

## 3. Risk and resilience value

Examples:
- cyber controls;
- disaster recovery;
- identity governance;
- unsupported-platform retirement;
- regulatory evidence automation.

Measures:
- exposure reduction;
- control coverage;
- recovery time;
- resilience testing outcomes;
- incidents avoided or reduced;
- audit exceptions;
- risk treatment progress.

Avoid pretending uncertain loss avoidance is guaranteed cash ROI.

## 4. Experience value

Examples:
- employee self-service;
- improved customer journey;
- faster response;
- reduced login or workflow friction.

Measures:
- adoption;
- satisfaction;
- task completion;
- error rate;
- response time;
- customer/employee effort.

## 5. Strategic capability value

Examples:
- scalable integration;
- data platform;
- M&A readiness;
- modern identity;
- AI enablement;
- reusable architecture.

Measures:
- time to launch;
- time to integrate;
- reuse;
- scalability;
- number of dependent initiatives enabled;
- reduction in structural constraints.

Strategic value often appears as **optionality**: the organisation can do something tomorrow that it could not do safely or economically today.
