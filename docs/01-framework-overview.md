# Framework Overview

Technology financial management is not simply budget administration.

A mature technology function needs to answer four questions at the same time:

1. **What does technology cost?**
2. **Why does it cost that amount?**
3. **Where should the next dollar be invested?**
4. **What business value did prior investments create?**

The framework connects financial discipline with value realisation.

## Master model

**Business Need → Baseline → Options → Cost → Expected Value → Risk → Priority → Investment → Adoption → Benefit → Review**

The model deliberately separates **cost**, **expected value** and **realised value**.

A business case can be approved and a project can be delivered without the expected value being realised. Adoption, operational change and benefit ownership matter.

## Two responsibilities

Technology leadership has two related responsibilities:

### Run the technology estate well
- budget and forecast accurately;
- understand fixed and variable cost drivers;
- manage contracts and commitments;
- control cloud/SaaS consumption;
- remove duplication and waste;
- maintain sustainable service levels.

### Invest for business value
- understand the business need;
- establish the baseline;
- compare options;
- account for total cost and risk;
- prioritise across the portfolio;
- define measurable benefits;
- review realised outcomes.

## Why this matters

An IT budget can increase while enterprise cost falls.

A security investment can have weak conventional ROI but strong risk value.

A platform replacement can initially raise cost while removing a structural constraint on growth.

Technology value therefore needs more than one lens.
