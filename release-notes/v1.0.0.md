# v1.0.0 — Stable Reference

Initial stable release of **Technology Financial Management & Value Realisation**.

## Included
- technology cost model and cost transparency;
- budget, forecast and P&L discipline;
- five technology value lenses;
- investment prioritisation;
- business cases and responsible use of ROI;
- benefits realisation;
- executive value scorecards and reporting;
- FinOps, SaaS and cost optimisation;
- worked examples covering vendor consolidation and security/resilience;
- reusable templates and diagrams;
- publication-ready article draft.

## Core proposition
Technology should be financially disciplined without allowing its value to be reduced to whether the IT budget went up or down.

No immediate follow-on release is planned. The framework should evolve from practical use, review and real examples.
